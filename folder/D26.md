D26 should be the **deployment/actuation compilation gate**, not a disguised runtime-observation gate. It should consume the D25 implementation and its actuator proofs, establish a deterministic deployable artifact, deploy only within explicit authority, and stop before claiming runtime behavior or production success.

# VS-D26 — DEPLOYMENT COMPILATION & CONTROLLED ACTUATION

## 0. GATE IDENTITY

Gate: `VS-D26`

Phase: `Deployment Compilation / Controlled Actuation`

Status on entry: `NOT AUTHORIZED`

Primary purpose:

> Compile the verified D25 implementation into a deployable runtime artifact, validate the complete upstream provenance and deployment contract, and—only where explicitly authorized—actuate that artifact into a bounded non-production deployment environment.

D26 is **not** a runtime-observation gate.

D26 must not interpret runtime behavior, claim production readiness, optimize the implementation, evolve the architecture, mutate the ISR, or make an evolution decision.

The conceptual pipeline is:

```text
D22  REQUIREMENT OBJECTIVE
  ↓
D23  CANDIDATE GENERATION
  ↓
D24  ARCHITECTURE SELECTION
  ↓
D25  IMPLEMENTATION COMPILATION
  ↓
D26  DEPLOYMENT COMPILATION + CONTROLLED ACTUATION
  ↓
D27  RUNTIME OBSERVATION
  ↓
D28  EVIDENCE INTERPRETATION
  ↓
D29  EVOLUTION DECISION
```

D26 therefore proves:

```text
verified implementation
        ↓
deployable artifact
        ↓
deployment identity
        ↓
bounded authorized actuation
```

It does **not** prove:

```text
runtime correctness
production readiness
performance
operational fitness
evolutionary superiority
```

Those belong downstream.

# 1. GOVERNING PRINCIPLES

The following are constitutional requirements.

### 1.1 ISR remains authoritative

The D25 implementation may compile from the selected architecture, but D26 must never modify, reinterpret, or regenerate the ISR.

The canonical ISR remains:

```text
48e53dcef47aad84e52e20ec116f5b1f961a626f42d1c281e3cc26cdf8e9dfb
```

Any ISR mutation is an immediate `BLOCKED` condition.

---

### 1.2 Upstream evidence is immutable

D26 consumes:

* D22 objective admission
* D23 candidate generation
* D24 architecture selection
* D25 implementation

It must not rewrite:

* D22 artifacts
* D23 artifacts
* D24 artifacts
* D25 artifacts
* historical D01–D21 artifacts
* the ISR
* the parent implementations

D26 artifacts must have distinct identities.

---

### 1.3 Deployment is not implementation

D26 must consume the D25 implementation.

It must not regenerate the implementation from the objective or candidate.

The selected architecture is:

```text
vs1-obj001-candidate-313b071dd7d4
```

The implementation is:

```text
vs1-impl-obj001-v1
```

D26 must deploy **that implementation**, not independently reconstruct it.

---

### 1.4 Deployment is not observation

A successful deployment means:

```text
the deployment mechanism successfully actuated the declared artifact
```

It does not mean:

```text
the software behaves correctly at runtime
```

Runtime behavior belongs to D27.

Therefore D26 must not convert:

* container/process started
* endpoint became reachable
* deployment command succeeded
* health check returned a response

into claims of functional correctness unless those checks are explicitly defined as deployment-integrity checks rather than behavioral evidence.

---

### 1.5 No production deployment

Unless a separate production authorization is explicitly supplied, D26 must not deploy to production.

For this gate:

```text
production_authorization = NONE
production = FALSE
```

Any attempt to actuate production is `BLOCKED`.

# 2. D26 AUTHORITY CONTRACT

D26 has exactly two possible operating modes.

## Mode A — PLAN ONLY

Plan-only mode:

* verifies the complete upstream chain
* validates the deployment specification
* constructs the canonical deployment plan
* computes deployment identity
* verifies artifact integrity
* validates authority
* performs zero deployment writes
* performs zero runtime mutation
* produces no deployed-state claim

Expected result:

```text
PLAN_VALID
```

or:

```text
BLOCKED
```

---

## Mode B — AUTHORIZED ACTUATION

Actuation mode requires an explicit deployment authorization.

The authorization must identify:

```text
authorization_id
implementation_id
implementation_hash
deployment_target
deployment_scope
environment
allowed_actions
expiration or validity semantics
```

The authorization must explicitly permit the deployment operation.

The following are insufficient:

* objective admission
* candidate generation authorization
* architecture selection
* implementation authorization
* D25 PASS
* existence of a deployment handoff
* existence of a deployment script
* operator intent implied by prose
* a filename containing "deploy"
* an environment variable
* a test fixture

No implicit authority.

# 17. DEPLOYMENT INTEGRITY CHECKS

Permitted examples:


def canonical_json(obj: Any) -> str:
    return json.dumps(
        obj,
        sort_keys=True,
        separators=(",", ":"),
        ensure_ascii=False,

def canonical_bytes(obj: Any) -> bytes:
    return canonical_json(obj).encode("utf-8")


def sha256_bytes(data: bytes) -> str:
    return hashlib.sha256(data).hexdigest()


def sha256_obj(obj: Any) -> str:
    return sha256_bytes(canonical_bytes(obj))


def sha256_file(path: Path) -> str:

def normalize_ref(ref: Any) -> str:
    if not isinstance(ref, str):

def ensure_false_flags(data: Dict[str, Any], flags: Iterable[str], label: str) -> None:
    for flag in flags:
        value = data.get(flag)
        if value is False:

        if str(value).strip().upper() in FALSE_VALUES:
            continue

def load_and_hash_json(path: Path, label: str) -> tuple[Dict[str, Any], Set[str], str]:
    path = Path(path)
    if not path.is_file():
        raise FailClosed(f"{label} artifact missing: {path}")

    raw_sha = sha256_file(path).lower()

    try:
        data = json.loads(path.read_text(encoding="utf-8"))
    except Exception as exc:
        raise FailClosed(f"{label} artifact is not valid canonical JSON: {path}: {exc}")

    if not isinstance(data, dict):
        raise FailClosed(f"{label} artifact must contain a JSON object: {path}")

    logical_sha = sha256_obj(data).lower()
    return data, {raw_sha, logical_sha}, raw_sha

    if isinstance(candidates, dict):

        for candidate_id, candidate in candidates.items():

                item.setdefault("candidate_id", candidate_id)

                        "candidate_hash": candidate,

                )

            break

        "d23_hash": sha256_obj(data),
        "d23_file_sha256": raw_sha,

def validate_deployment_spec(spec: Dict[str, Any]) -> str:
    required = [
        "environment",
        "target",
        "backend",
        "runtime",
        "entrypoint",
        "health",
        "configuration_contract",
    ]
    for key in required:
        if key not in spec:
            fail(f"deployment specification missing required field: {key}")

    environment = str(spec.get("environment") or "").strip().lower()
    if not environment:
        fail("deployment environment missing")
    if environment in PRODUCTION_ENVIRONMENTS:
        fail("production deployment is not authorized")

    if spec.get("production") is True:
        fail("production flag must be false")

    rollback_required = spec.get("rollback_required", True)
    if rollback_required and not spec.get("rollback_identity"):
        fail("rollback is required but rollback_identity is missing")

    closure = spec.get("source_closure", {})
    if not isinstance(closure, dict):
        fail("deployment specification source_closure must be an object")

    source_root = str(closure.get("root") or "vertical_slice/app_v3")
    if not source_root:
        fail("deployment specification source_closure.root missing")

    return source_root


def is_excluded(rel_path: str, extra_excludes: Set[str]) -> bool:
    parts = Path(rel_path).parts

    for part in parts:
        if part in DEFAULT_EXCLUDE_DIRS:
            return True
        if part in extra_excludes:
            return True

    for suffix in DEFAULT_EXCLUDE_SUFFIXES:
        if rel_path.endswith(suffix):
            return True

    if rel_path.startswith("tests/") or "/tests/" in rel_path:
        return True

    if Path(rel_path).name.startswith("test_"):
        return True

    return False


def classify_role(rel_path: str) -> str:
    if rel_path.endswith(".py"):
        return "runtime"
    if rel_path.endswith((".json", ".yaml", ".yml", ".toml")):
        return "configuration"
    if rel_path.endswith(".txt"):
        return "dependency"
    if rel_path.endswith(".md"):
        return "documentation"
    return "asset"


def build_artifact_manifest(
    root: Path,
    source_root: str,
    spec_excludes: List[str],
) -> Dict[str, Any]:
    source_path = root / source_root
    if not source_path.is_dir():
        fail(f"deployment source root missing: {source_path}")

    extra_excludes = {normalize_ref(item) for item in spec_excludes if item}
    files: List[Dict[str, Any]] = []

    for path in sorted(source_path.rglob("*"), key=lambda p: p.as_posix()):
        if path.is_dir():
            continue

        rel_path = path.relative_to(root).as_posix()
        if is_excluded(rel_path, extra_excludes):
            continue

        files.append(
            {
                "relative_path": rel_path,
                "sha256": sha256_file(path).lower(),
                "size": path.stat().st_size,
                "role": classify_role(rel_path),
            }
        )

    if not files:
        fail("deployment artifact closure is empty")

    manifest = {
        "source_root": source_root,
        "files": files,
    }

    return manifest


def scan_text_for_secrets(text: str, rel_path: str) -> List[Dict[str, Any]]:
    diagnostics: List[Dict[str, Any]] = []

    for line_number, line in enumerate(text.splitlines(), start=1):
        if SYNTHETIC_SECRET_MARKER in line:
            continue

        for pattern_name, pattern in SECRET_PATTERNS:
            if pattern.search(line):
                diagnostics.append(
                    {
                        "pattern": pattern_name,
                        "path": rel_path,
                        "line": line_number,
                    }
                )

    return diagnostics


def scan_manifest_files(root: Path, manifest: Dict[str, Any]) -> List[Dict[str, Any]]:
    diagnostics: List[Dict[str, Any]] = []

    for entry in manifest["files"]:
        rel_path = entry["relative_path"]
        path = root / rel_path

        if entry["size"] > MAX_SCANNABLE_TEXT_BYTES:
            raise FailClosed(
                f"file too large for secret scan and not safely deployable: {rel_path}"
            )

        raw = path.read_bytes()

        try:
            text = raw.decode("utf-8")
        except UnicodeDecodeError:
            raise FailClosed(
                f"binary or non-UTF8 file present in deployment closure: {rel_path}"
            )

        diagnostics.extend(scan_text_for_secrets(text, rel_path))

    return diagnostics


def compute_deployment_identity(
    spec: Dict[str, Any],
    spec_hash: str,
    manifest_hash: str,
    d25: Dict[str, Any],
) -> tuple[str, str]:
    payload = {
        "implementation_id": d25["implementation_id"],
        "implementation_hash": d25["implementation_hash"],
        "artifact_manifest_hash": manifest_hash,
        "deployment_spec_hash": spec_hash,
        "environment": spec["environment"],
        "target": spec["target"],
        "backend": spec["backend"],
        "runtime": spec["runtime"],
        "configuration_contract": spec.get("configuration_contract", {}),
        "policy_version": POLICY_VERSION,
    }

    deployment_hash = sha256_obj(payload).lower()
    deployment_id = f"vs1-deploy-obj001-{deployment_hash[:16]}"
    return deployment_hash, deployment_id


def verify_authorization(
    root: Path,
    authorization_path: str,
    spec: Dict[str, Any],
    d25: Dict[str, Any],
    deployment_id: str,
    deployment_hash: str,
    require_actuation: bool,
) -> Dict[str, Any]:
    authorization, _, _ = load_and_hash_json(
        root / normalize_ref(authorization_path),
        "deployment authorization",
    )

    required = [
        "authorization_id",
        "implementation_id",
        "implementation_hash",
        "deployment_target",
        "deployment_scope",
        "environment",
        "allowed_actions",
    ]
    for key in required:
        if key not in authorization:
            fail(f"deployment authorization missing required field: {key}")

    if authorization.get("implementation_id") != d25["implementation_id"]:
        fail("authorization implementation_id mismatch")

    if str(authorization.get("implementation_hash") or "").lower() != d25["implementation_hash"]:
        fail("authorization implementation_hash mismatch")

    if authorization.get("deployment_target") != spec.get("target"):
        fail("authorization deployment_target mismatch")

    if str(authorization.get("environment") or "").lower() != str(spec.get("environment") or "").lower():
        fail("authorization environment mismatch")

    if str(authorization.get("deployment_id") or "") not in ("", deployment_id):
        fail("authorization deployment_id mismatch")

    if str(authorization.get("deployment_hash") or "") not in ("", deployment_hash):
        fail("authorization deployment_hash mismatch")

    production_authorization = authorization.get("production_authorization", False)
    if production_authorization is not False:
        fail("production authorization must be false")

    allowed_actions = authorization.get("allowed_actions", [])
    if not isinstance(allowed_actions, list):
        fail("authorization allowed_actions must be a list")

    if require_actuation and "actuate_bounded_deployment" not in allowed_actions:
        fail("authorization does not permit bounded deployment actuation")

    expires_at = authorization.get("expires_at")
    if expires_at:
        try:
            expiry = datetime.fromisoformat(str(expires_at).replace("Z", "+00:00"))
        except Exception:
            fail("authorization expires_at is not valid ISO-8601")

        if expiry.tzinfo is None:
            expiry = expiry.replace(tzinfo=timezone.utc)

        if expiry <= datetime.now(timezone.utc):
            fail("deployment authorization expired")

    return authorization


def verify_test_evidence(root: Path, test_evidence_path: str) -> Dict[str, Any]:
    data, _, _ = load_and_hash_json(root / normalize_ref(test_evidence_path), "test evidence")

    required = [
        "d26",
        "d25",
        "d24",
        "d23",
        "d22",
        "tests_vs1",
        "adjacent_suites",
        "full_regression",
    ]

    for key in required:
        if key not in data:
            fail(f"test evidence missing field: {key}")

    full_regression = str(data.get("full_regression") or "").upper()
    if full_regression not in {"COMPLETE", "NOT_COMPLETE"}:
        fail("test evidence full_regression must be COMPLETE or NOT_COMPLETE")

    return data


def redact(obj: Any) -> Any:
    secret_markers = (
        "password",
        "secret",
        "token",
        "credential",
        "private_key",
        "session",
        "cookie",
        "api_key",
    )

    if isinstance(obj, dict):
        return {
            key: redact(value)
            for key, value in obj.items()
            if not any(marker in str(key).lower() for marker in secret_markers)
        }

    if isinstance(obj, list):
        return [redact(item) for item in obj]

    return obj


def write_canonical_json(path: Path, obj: Any) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(canonical_json(obj), encoding="utf-8")


def ensure_not_overwrite_upstream(
    outputs: Dict[str, Path],
    inputs: List[str],
    root: Path,
) -> None:
    input_paths = set()
    for item in inputs:
        if item:
            input_paths.add((root / normalize_ref(item)).resolve())

    for output_path in outputs.values():
        if output_path.resolve() in input_paths:
            fail(f"D26 output would overwrite an upstream artifact: {output_path}")


def snapshot_files(paths: Iterable[Path]) -> Dict[str, str]:
    result: Dict[str, str] = {}
    for path in paths:
        if path.is_file():
            result[str(path.resolve())] = sha256_file(path).lower()
    return result


def verify_snapshot(before: Dict[str, str], after: Dict[str, str]) -> None:
    if before != after:
        fail("upstream artifact mutation detected during D26 execution")

def write_artifacts(
    outputs: Dict[str, Path],
    state: Dict[str, Any],
    evidence: Dict[str, Any],
    manifest_obj: Dict[str, Any],
    handoff: Dict[str, Any],
    spec: Dict[str, Any],
    report: str,
) -> None:
    write_canonical_json(outputs["manifest"], manifest_obj)
    write_canonical_json(outputs["evidence"], evidence)
    write_canonical_json(outputs["handoff"], handoff)
    write_canonical_json(outputs["spec"], spec)

    manifest_json = canonical_json(manifest_obj)
    manifest_literal = json.dumps(manifest_json)

    deployment_py = "\n".join(
        [
            '"""Deterministic D26 deployment manifest."""',
            "import json",
            "",
            f"DEPLOYMENT_ID = {json.dumps(state['deployment_id'])}",
            f"DEPLOYMENT_HASH = {json.dumps(state['deployment_hash'])}",
            "",

            "",
            "def main() -> None:",
            "    print(json.dumps(MANIFEST, sort_keys=True, indent=2))",
            "",
            "",
            'if __name__ == "__main__":',
            "    main()",
            "",
        ]
    )

    outputs["deployment_py"].parent.mkdir(parents=True, exist_ok=True)
    outputs["deployment_py"].write_text(deployment_py, encoding="utf-8")

    markdown = "\n".join(
        [

            "",
            "This document is generated by the D26 Deployment Authority Actuator.",
            "",
            "```text",
            report,
            "```",
            "",
        ]
    )

    outputs["markdown"].parent.mkdir(parents=True, exist_ok=True)
    outputs["markdown"].write_text(markdown, encoding="utf-8")


def run_d26(args: argparse.Namespace) -> int:
    root = Path(args.root).resolve()
    firewall = ActionFirewall()

    input_paths = [
        args.objective_source,
        args.d22,
        args.d23,
        args.d24,
        args.isr,
        args.d25_manifest,
        args.d25_handoff,
        args.d25_behavior_evidence,
        args.d25_actuator,
        args.d25_test,
        args.deployment_spec,
        args.authorization,
        args.test_evidence,
    ]

    try:
        firewall.authorize("verify_upstream")

        objective_source = verify_objective_source(root, args.objective_source)
        d22 = verify_d22(root, args.d22, objective_source)
        d23 = verify_d23(root, args.d23)
        d24 = verify_d24(root, args.d24, d23, args.d24_adapter)
        isr = verify_isr(root, args.isr)
        d25 = verify_d25(
            root,
            args.d25_manifest,
            args.d25_handoff,
            args.d25_behavior_evidence,
            args.d25_actuator,
            args.d25_test,
        )

        firewall.authorize("compile_deployment")

        spec, spec_hashes, _ = load_and_hash_json(
            root / normalize_ref(args.deployment_spec),
            "deployment specification",
        )
        spec_hash = sha256_obj(spec).lower()
        validate_deployment_spec(spec)

        closure = spec.get("source_closure", {})
        source_root = str(closure.get("root") or "vertical_slice/app_v3")
        spec_excludes = closure.get("exclude", [])
        if not isinstance(spec_excludes, list):
            fail("deployment specification source_closure.exclude must be a list")

        manifest = build_artifact_manifest(root, source_root, spec_excludes)
        manifest_hash = sha256_obj(manifest).lower()

        entrypoint = str(spec.get("entrypoint") or "")
        if entrypoint:
            entrypoint_found = any(
                item["relative_path"] == entrypoint for item in manifest["files"]
            )
            if not entrypoint_found:
                fail("deployment entrypoint is not present in the deployment closure")

        firewall.authorize("scan_artifact")
        secret_diagnostics = scan_manifest_files(root, manifest)
        if secret_diagnostics:
            fail(
                "secret scan failed: "
                + ", ".join(
                    f"{item['pattern']}@{item['path']}:{item['line']}"
                    for item in secret_diagnostics[:5]
                )
            )

        deployment_hash, deployment_id = compute_deployment_identity(
            spec,
            spec_hash,
            manifest_hash,
            d25,
        )

        # Determinism check: same logical inputs must yield same deployment identity.
        manifest_repeat = build_artifact_manifest(root, source_root, spec_excludes)
        manifest_repeat_hash = sha256_obj(manifest_repeat).lower()

        deployment_hash_repeat, deployment_id_repeat = compute_deployment_identity(
            spec,
            spec_hash,
            manifest_repeat_hash,
            d25,
        )

        if manifest_hash != manifest_repeat_hash:
            fail("deployment artifact manifest is not reproducible")

        if deployment_hash != deployment_hash_repeat or deployment_id != deployment_id_repeat:
            fail("deployment identity is not reproducible")

        authorization = None
        if args.authorization:
            authorization = verify_authorization(
                root,
                args.authorization,
                spec,
                d25,
                deployment_id,
                deployment_hash,
                require_actuation=args.actuate,
            )
        elif args.actuate:
            fail("actuation requires explicit deployment authorization")

        if args.actuate:
            fail(
                "no bounded DeploymentBackend is configured in this reference actuator; "
                "actuation must be performed by an explicit target adapter"
            )

        if args.plan_only:
            print(
                canonical_json(
                    {
                        "status": "PLAN_VALID",
                        "deployment_id": deployment_id,
                        "deployment_hash": deployment_hash,
                        "artifact_manifest_hash": manifest_hash,
                        "deployment_spec_hash": spec_hash,
                        "environment": spec["environment"],
                        "target": spec["target"],
                        "backend": spec["backend"],
                        "implementation_id": d25["implementation_id"],
                        "implementation_hash": d25["implementation_hash"],
                        "actuation": "NOT_PERFORMED",
                        "production": False,
                        "runtime_observation": "NOT_PERFORMED",
                    }
                )
            )
            return 0

        if not args.write:
            fail("D26 evidence emission requires --write; use --plan-only for zero-write plan validation")

        if not args.test_evidence:
            fail("D26 PASS evidence requires --test-evidence")

        test_summary = verify_test_evidence(root, args.test_evidence)

        outputs = {
            "manifest": root / args.out_dir / "deployment_d26_manifest.json",
