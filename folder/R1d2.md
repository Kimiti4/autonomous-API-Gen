# 12. COMPILER IR VS ARCHITECTURE MODEL

Do not duplicate architectural intent.

Architecture Model answers:

```text
What architecture should exist?
```

Compiler IR answers:

```text
What implementation-oriented representation is required to lower that architecture?
```

The boundary must be explicit.

Example:

```text
Architecture Model:

"System has an authentication service."

Compiler IR:

"Authentication service exposes operation X,
requires credential validation capability,
has persistence dependency Y,
and has interface contract Z."
```

The Compiler IR should be more concrete than Architecture Model but still backend-neutral.
